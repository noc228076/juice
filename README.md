## 🛠️ 二次开发指南

### 1. 题目与选项定制 (`js/data.js`)
编辑 `QUESTIONS` 数组即可添加或修改测试题目：
```javascript
{
  q: '题干内容……',
  opts: [
    { t: '选项 A 文案', k: 'E' }, // k 对应计分字母: E/I, S/N, T/F, J/P
    { t: '选项 B 文案', k: 'I' },
    { t: '选项 C 文案', k: 'J' },
    { t: '选项 D 文案', k: 'P' }
  ]
}
```
*计分逻辑：每选一项对应维度 +2 分，最终比对四组维度得分裁定 MBTI 编码。*

### 2. 饮料人格与配方定制 (`js/data.js`)
编辑 `PERSONAS` 对象中的 16 种人格属性（如 `ESTP`, `INFJ` 等）：
- `name`: 饮料中文名（如 `爆珠可乐`、`桂花乌龙`）
- `en`: 英文名称
- `color`: 主题色 Hex 码（会动态渲染到结果卡色带）
- `tags`: 个性标签
- `desc`: 详细配方与性格解读
- `ingredients`: 性格成分比例条（用于营养成分表展示）
- `shine` / `warn` / `match` / `quote`: 闪光点、雷区、绝配饮料、金句

### 3. 主题与视觉样式 (`css/style.css`)
- **双主题支持**：在 `:root`、`html[data-theme="dark"]` 和 `html[data-theme="light"]` 中配置颜色变量（如青柠荧光绿 `--ac`、背景 `--bg`、卡片 `--card`）。
- **宽屏与移动端适配**：包含移动端触屏优化和桌面端自适应居中约束。

### 4. 浏览器音效系统 (`js/sfx.js`)
采用现代 **Web Audio API** 振荡器与噪声合成（无需加载任何 `.mp3` / `.wav` 音频文件，加载极快）：
- `SFX.tap()`: 按钮轻触
- `SFX.select()`: 选项选中反馈
- `SFX.pour()`: 注水声效
- `SFX.bubble()`: 随机小气泡音
- `SFX.shake()`: 摇杯摩擦音
- `SFX.reveal()`: 结果揭晓琶音

### 5. 分享海报生成 (`js/app.js`)
在 `drawShareCard()` 中使用原生 HTML5 Canvas 绘制 1080×1620 高清结果卡，浏览器下点击“保存分享卡”会自动生成并下载 PNG 图片。

## ✨ 针对浏览器与 PC 桌面端的深度适配

   - **左栏（粘性展示）**：包含 440px 高保真结果卡片、MBTI 色带、营养成分表、出品认证印章，以及一键保存分享卡与再摇一杯按钮。
